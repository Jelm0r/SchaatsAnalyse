the goal of this tool is to make life easier for speedskating coaches when doing video analyses. 
input is a video of a speedskater from the front on the straight. with that video the tool can already follow the whole body.
there are 2 things that I still need to make.

It also has a function to play movies directly from any place on the computer. this is made to directly analyse the training without the waitingtime. this function is without any automaic analysis. just a videoplayer with a few extra functions.
